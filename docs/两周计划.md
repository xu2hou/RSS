## 三、提交节奏要求

- 每个步骤至少 1 次提交；S02–S04、S13–S18 这类大功能拆成「数据层 → UI → 联调」2–3 次。
- 分支命名：`feature/xxx`、`fix/xxx`、`test/xxx`、`docs/xxx`；完成后 `git merge --no-ff` 回 `main`。
- 提交信息格式：`<type>: <中文说明>`，如 `feat: 实现订阅列表未读数徽标`。
- **禁止**：空提交、伪造作者或时间、一个提交塞多个不相关功能。
