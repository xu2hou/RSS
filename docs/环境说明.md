## 3. 网络坑与对策（重要）

| 源 | 实测 | 对策 |
|----|------|------|
| `dl.google.com` 上的 **Maven 制品**（AGP / AndroidX 大 jar） | 会挂住几分钟不下载，`BUILD` 卡死 | 必须用镜像 |
| `services.gradle.org`（Gradle 发行包） | 约 57 KB/s，130 MB 要几十分钟 | 用腾讯镜像 |
| `maven.aliyun.com/repository/{google,central}` | 快且稳定（毫秒级） | **首选** |
| `mirrors.cloud.tencent.com/gradle/` | 130 MB 约 8 秒 | Gradle 发行包首选 |

工程内固定写法：

```groovy
// settings.gradle
dependencyResolutionManagement {
    repositories {
        maven { url 'https://maven.aliyun.com/repository/google' }
        maven { url 'https://maven.aliyun.com/repository/central' }
        google()
        mavenCentral()
    }
}
```

```properties
# gradle/wrapper/gradle-wrapper.properties
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.9-bin.zip
```

## 4. 模拟器

| AVD 名 | 系统镜像 | 状态 |
|--------|----------|------|
| `Pixel_API35` | `android-35 / google_apis / x86_64` | ✅ 本次新建并验证可启动（40 秒进桌面） |
| `ToastDemo_API35` | `android-35 / default / x86_64` | 镜像存在，可用 |
| `Medium_Phone_API35` | `android-35 / google_apis_playstore / x86_64` | ❌ 镜像缺失，无法启动（如需用请补装该镜像） |

启动命令（带窗口，演示 / 录屏用）：

```powershell
$env:ANDROID_SDK_ROOT='D:\AndroidStudioSDK'
& 'D:\AndroidStudioSDK\emulator\emulator.exe' -avd Pixel_API35
```

无窗口（只做编译验证时用）：

```powershell
& 'D:\AndroidStudioSDK\emulator\emulator.exe' -avd Pixel_API35 -no-window -no-audio -gpu swiftshader_indirect
```
