# 录屏脚本与水印方案

> 交付要求：主 App 与伴生模块**各一段、各约 3 分钟**，界面须带**本人学号 + 姓名水印**，完整跑通核心流程。

## 一、水印方案（已做进 App）

本机没有 ffmpeg / OBS，后期叠字要额外装工具且容易漏帧，因此把水印做成了**应用内的真实功能**：

| 项 | 说明 |
|---|---|
| 实现 | `ui/widget/WatermarkOverlay.java`，在 `MainActivity` / `AddFeedActivity` / `ArticleDetailActivity` / `BackupActivity` 的 `onCreate` 里挂到 `android.R.id.content` 上 |
| 文案 | `202405100113 邬逸帆` |
| 样式 | 左下角、半透明黑底（#66000000）+ 白字（#CCFFFFFF）、11sp、抬高 128dp 避开底部导航 |
| 开关 | 设置页 →「显示演示水印（学号 + 姓名）」，默认**开启**，切换后立即重建页面生效 |

优点：位置、透明度稳定可复现，录屏天然带水印，不需要任何后期处理。

> 若老师要求水印在**右上角**或想要更大字号，改 `WatermarkOverlay` 里的 `gravity` 与 `textSize` 即可，一处生效全部页面。

## 二、录制方法

| 项 | 建议 |
|---|---|
| 工具 | Windows 自带 **Win + G**（Xbox Game Bar）→ 捕获 → 勾选「Android Emulator - Pixel_API35」窗口 → 开始录制 |
| 分辨率 | 模拟器窗口 1080×2400；录完不必裁剪，横屏播放器会自动适配 |
| 声音 | 旁白可后配，也可现场讲；若要现场讲，先测试麦克风电平 |
| 存放 | `202405100113-邬逸帆-主App演示.mp4`、`202405100113-邬逸帆-伴生模块演示.mp4` |
| 注意 | 录屏前在设置页确认水印开关是**开**的；录完看一眼首尾帧水印都在 |

## 三、主 App 分镜（约 3:00）

| 时间 | 画面 | 操作 | 旁白要点 |
|---|---|---|---|
| 0:00–0:20 | 桌面 | 展示桌面上**两个图标**：阅流 RSS、备份与恢复 | 「这是主 App 和伴生模块，一会儿分别演示」 |
| 0:20–0:50 | 订阅页（空态） | 点 + → 添加订阅页 → 点「少数派」→ 点「添加订阅」→ 返回列表 | 「空态不是白屏，有引导文案；地址可以先校验再抓取，失败会回显原因」 |
| 0:50–1:20 | 订阅列表 | 下拉刷新 → 看到「刷新完成：成功 N 个，新增 M 篇」 | 「真实的网络请求，抓到多少篇会明确告诉你」 |
| 1:20–1:45 | 断网错误态 | 打开飞行模式 → 下拉刷新 → 出现 Snackbar → 点「重试」→ 关闭飞行模式 | 「断网不会静默失败，会给中文原因和重试入口」 |
| 1:45–2:15 | 文章页 | 切「推荐 / 未读 / 收藏」→ 点某篇右侧星标 → 进「收藏」档确认 | 「推荐是按收藏、未读、源健康度加权并做时间衰减算出来的」 |
| 2:15–2:40 | 详情页 | 打开一篇文章 → 上下滑动看排版与图片 → 下拉通知栏切深色模式 → 再展示 | 「正文用 WebView 渲染，CSS 做了图片自适应与深色适配」 |
| 2:40–3:00 | 设置页 | 展示「后台任务状态：ENQUEUED」与通知权限状态 | 「后台刷新由 WorkManager 调度；通知被拒也不影响刷新和阅读」 |

## 四、伴生模块分镜（约 3:00）

| 时间 | 画面 | 操作 | 旁白要点 |
|---|---|---|---|
| 0:00–0:25 | 桌面 | 直接点**「备份与恢复」图标** | 「这是独立入口，不经过主 App 也能起来」 |
| 0:25–0:55 | 备份页 | 展示「当前数据：3 个订阅源、87 篇文章」→ 点「立即备份到本机」 | 「读的是主 App 的同一个数据库」 |
| 0:55–1:20 | 备份记录 | 指记录列表（文件名/时间/大小）→ 点右侧菜单展示「恢复 / 分享 / 删除」 | 「备份文件是纯 JSON，带版本号，将来升级也能兼容」 |
| 1:20–1:45 | 自动备份 | 打开「每日自动备份」开关 | 「WorkManager 每天一次，只保留最近 7 份」 |
| 1:45–2:20 | 导出 | 点「导出备份文件…」→ 选择位置 → 完成提示 | 「也可以导出到文件管理器/网盘，换机时用」 |
| 2:20–2:50 | 恢复 | 点某条记录 → 选「覆盖状态并恢复」→ 看结果统计 Toast | 「按 url 和 link 去重，重复导入不会产生重复数据」 |
| 2:50–3:00 | 异常 | 选一个非备份的 JSON 导入 → 提示「文件不是合法的备份 JSON」 | 「坏文件不会崩，会告诉你为什么」 |

## 五、录屏前自检清单

- [ ] 模拟器已启动，App 已安装最新 APK
- [ ] 设置页水印开关为**开**，画面上能看到「202405100113 邬逸帆」
- [ ] 订阅源至少 2 个（建议少数派 + 阮一峰，覆盖 RSS 与 Atom 两种格式）
- [ ] 文章数 > 50，备份文件大小会更有说服力
- [ ] 已授权通知权限（要演示通知时），或明确演示「被拒绝」的降级
- [ ] 录完检查首尾帧都在录、水印全程可见
