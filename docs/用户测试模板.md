# 用户测试报告模板（伴生模块产品化材料，占 10 分）

> 课程评分项：「用户测试报告 / 迭代说明」10 分。
> 用法：找 **3–5 位同学**试用，让他们独立完成下面 5 个任务，记录完成情况与反馈，然后把表填满。

## 二、测试任务（交给试用者，不解释）

| 编号 | 任务 | 完成判据 |
|---|---|---|
| T1 | 订阅「少数派」，并告诉我它有多少篇未读 | 列表出现该源且未读数正确 |
| T2 | 把「刷新」弄失败一次，然后恢复 | 能看到失败原因并重试成功 |
| T3 | 收藏一篇文章，再从「收藏」里找到它 | 收藏档出现该文章 |
| T4 | 在「备份与恢复」里做一次备份，然后找到这个文件 | 记录列表出现该文件 |
| T5 | 用这份备份把数据恢复回来 | 出现恢复结果统计，数据不重复 |
