## 五、技术栈（与代码一致，不可随意漂移）

| 层 | 选型 |
|---|---|
| 语言 / UI | Java 17 + XML View（原生 Android，非跨平台；Compose 仅支持 Kotlin，故不用） |
| 架构 | MVVM：Activity/Fragment → ViewModel → Repository → Room / 网络 |
| 异步 | ViewModel + LiveData + ExecutorService（Java 下替代协程的标准方案） |
| 持久化 | Room 2.6.1（+ SharedPreferences 存偏好） |
| 网络 | OkHttp 4.12.0 |
| XML 解析 | Android 内置 XmlPullParser（流式，不引第三方） |
| 后台任务 | WorkManager 2.9.1 |
| 构建 | Gradle 8.9 + AGP 8.7.3，compileSdk/targetSdk 35，minSdk 24 |

## 七、同题个性化差异（待确认）

指南要求同题按学号分配功能子集。本项目已实现的差异点：

1. **RSS 2.0 + Atom 双格式支持**（多数实现只做 RSS 2.0）
2. **自定义推荐排序算法**（收藏/未读/源健康度加权 + 时间衰减）
3. **订阅源健康度与指数退避**（连续失败自动降级，避免坏源拖垮整轮刷新）
4. **伴生模块 P6**：JSON 备份 + 合并式恢复 + 每日自动备份滚动保留 7 份
